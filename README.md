# 《時間入罐｜一日完成，時間延續》

用一天的時間完成製作，  
讓時間在之後慢慢發生。

---

## 活動介紹

《時間入罐》不是一次性結束的 DIY 課程。  
我們把「製作」與「等待」拆開，讓真正的變化發生在你回到日常生活之後。

陶罐需要燒製，  
發酵需要時間，  
味道真正穩定，往往不在教室裡完成。

---

## 一日完成，發生在之後

在一天之內，你會完成：

- **親手製作一只陶罐**  
  為發酵而生的容器，課後燒製，約一個月完成，可自取或寄送。

- **完成一罐可立即帶回家的玻璃罐漬物**  
  當天封存，把變化帶回生活中。

真正的重點不是「完成」，  
而是之後你開始觀察、等待，理解時間如何作用在味道與器物上。

## 四季計畫的一部分

一年，我們只做四件事：

- **🌸 春｜梅子的時間**  
  短暫、錯過、等待，在成熟期完成封存，發酵在生活中慢慢發生。

- **🌿 夏｜蔬菜的轉變**  
  變化、控制、判斷，學習比例與風味高峰的掌握。

- **🍂 秋｜米麴**  
  轉化、基礎、累積，從看不見的地方開始改變。

- **❄️ 冬｜長時間熟成**  
  慢、陪伴、回顧，讓味道自己變深。

本次《時間入罐》為**春季的一日體驗版本**，  
讓你先理解整個計畫的核心。
